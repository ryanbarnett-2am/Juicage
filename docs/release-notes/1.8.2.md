## Juicage was using far too much disk

If you've been running Juicage for a while, it had quietly accumulated up to **a gigabyte** of files. This release gets it back and stops it happening again.

**The web cache had no ceiling.** Juicage keeps a hidden web view parked on claude.ai to read your usage, and every asset that page loaded was cached with nothing ever clearing it — on one machine, 585 MB across nearly 10,000 files. Caches are now cleared at launch and every six hours. Your sign-in is untouched; only cached responses go.

**A leftover folder from the sandbox change.** Before v1.6, Juicage ran in the App Sandbox and stored everything under `~/Library/Containers/twoam.Tally`. Turning the sandbox off — required to see local Ollama and LM Studio activity — moved all of that elsewhere and stranded the old copy, where nothing would ever read it again. It was still there, around 577 MB. Juicage now removes it once, on first launch.

Nothing you care about is affected: your history, settings and claude.ai sign-in all live elsewhere and are left alone.

## Also

The README now explains why you'll see `twoam.Tally` in file paths when the app is called Juicage — it's the original name, frozen deliberately so that renaming the app didn't sign everyone out.

Download the `.dmg`, open it, and drag Juicage onto Applications. Or `brew upgrade --cask juicage`.
