## Fixes Juicage using a full CPU core

If you use LM Studio, Juicage could get stuck using an entire CPU core — all day, on battery — after LM Studio restarted.

Juicage watches LM Studio's log to show which task a local model is working on. When LM Studio restarted, that log closed, and Juicage kept checking the closed log in a tight loop instead of letting go. It also never reconnected, so task titles stopped showing too.

It now lets go when the log closes and reconnects on its own. This was present since 1.4, and only affected people running LM Studio.
